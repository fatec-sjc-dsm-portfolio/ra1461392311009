---

## 🚀 Tecnologias Utilizadas no Portfólio

* **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide Icons
* **Build & Bundler:** Vite 6
* **Deploy & CI/CD:** GitHub Actions (branch `main`) para GitHub Pages oficial da FATEC SJC

---

## 🛠️ Como Executar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev

# 3. Compilar versão de produção
npm run build
```

---

## 🌐 Deploy Automático via GitHub Actions

O deploy é automatizado diretamente da branch `main` via GitHub Actions (`.github/workflows/deploy.yml`):
* A cada `git push origin main`, a Action compila a aplicação com TypeScript e publica diretamente no GitHub Pages oficial:
👉 **[https://fatec-sjc-dsm-portfolio.github.io/ra1461392311009/](https://fatec-sjc-dsm-portfolio.github.io/ra1461392311009/)**
